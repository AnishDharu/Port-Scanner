# 🔍 Simple Python Port Scanner

A lightweight and customizable Python script that scans a target (or multiple targets) for open ports and displays the corresponding common service names (e.g., FTP, HTTP, SSH).

---

## 📌 Features

- Scans for open **TCP** ports on a target IP address or domain
- Identifies common services (like SSH, HTTP, etc.) by port number
- Supports **scanning multiple targets** at once
- **Color-coded** terminal output using `termcolor`
- Easy to modify and expand

---

## ⚙️ Requirements

- Python 3.x
- `termcolor` package
